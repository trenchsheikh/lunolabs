# Luno Labs

Marketing site for **Luno Labs** — a small software studio that builds custom booking systems, websites, internal tools and AI automations for small businesses.

A single-page editorial landing site built on the Next.js App Router. Includes smooth scrolling, on-scroll section reveals, a Calendly booking flow, a contact form, and full SEO (metadata, Open Graph, sitemap, robots, and JSON-LD structured data).

## Tech stack

- **[Next.js 14](https://nextjs.org/)** (App Router) · **React 18** · **TypeScript**
- **[Tailwind CSS](https://tailwindcss.com/)** with **[shadcn/ui](https://ui.shadcn.com/)** components on **[Radix UI](https://www.radix-ui.com/)**
- **[Lenis](https://lenis.darkroom.engineering/)** — smooth scrolling
- **[react-hook-form](https://react-hook-form.com/)** + **[Zod](https://zod.dev/)** — contact form validation
- **[Calendly](https://calendly.com/)** embeds — inline widget, badge widget, and popup CTA
- **Manrope** (UI) + Times New Roman (display serif) typography

## Getting started

**Prerequisites:** Node.js 18.17+ and npm.

```bash
# 1. Install dependencies
npm install

# 2. Configure environment (optional — see below)
cp env-template.txt .env.local

# 3. Start the dev server
npm run dev
```

The site runs at [http://localhost:3000](http://localhost:3000).

## Environment variables

All are optional — the site builds and runs without a `.env.local`.

| Variable | Used by | Default |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical URL, Open Graph tags, sitemap, robots, JSON-LD | `https://lunolabs.com` |
| `NEXT_PUBLIC_CALENDLY_INLINE_URL` | The inline Calendly embed (use your event-type link) | Studio default in `lib/calendly.ts` |
| `EMAIL_USER` / `EMAIL_PASSWORD` | Legacy `app/api/contact` Nodemailer route (the live contact form posts to FormSubmit instead) | — |

> Note: the visible contact form submits via [FormSubmit](https://formsubmit.co/); the `app/api/contact` route is kept for reference and is not wired into the UI.

## SEO

- Site-wide metadata (title, description, keywords, canonical, Open Graph, Twitter cards, robots) lives in `app/layout.tsx`, sourced from `lib/site.ts`.
- `sitemap.xml` and `robots.txt` are generated by `app/sitemap.ts` / `app/robots.ts`.
- JSON-LD structured data in `components/json-ld.tsx`: `ProfessionalService` (with a service catalog), `WebSite`, and a `FAQPage` generated from the FAQ content so the markup always matches what's on the page.
- To point everything at a different domain, set `NEXT_PUBLIC_SITE_URL`. A 1200×630 social-share image can be added to `public/` and referenced from `openGraph.images` / `twitter.images` in `app/layout.tsx`.

## Deployment

Optimised for [Vercel](https://vercel.com/) — push the repo, set `NEXT_PUBLIC_SITE_URL` (and any other env vars), and deploy. Any Node host that supports Next.js 14 also works (`npm run build && npm run start`).
